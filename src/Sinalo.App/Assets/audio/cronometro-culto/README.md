# Áudios do Cronômetro de Culto

Copie para esta pasta os áudios originais aprovados para uso pelo projeto, com estes nomes:

- `abertura_escsb.mp3`
- `5minutos_escsb.mp3`
- `1minuto_escsb.mp3`

Durante a publicação, os arquivos MP3 desta pasta são incluídos em
`assets/audio/cronometro-culto` ao lado do executável. Se algum arquivo não
estiver presente, o respectivo aviso é apenas ignorado e a contagem continua.
