Suporte

Resolver problemas comuns

Antes de tentar novamente, leia a mensagem mostrada pelo Sinalo. Ela costuma indicar se o problema é rede, espaço, arquivo ou tela de saída.

O aplicativo não encontrou vídeos para baixar.

Confira se a página oficial do programa está configurada corretamente e se existem arquivos oficiais publicados para o período escolhido. A regra de download define o que o Sinalo procura; ela não garante que já exista um arquivo disponível.

O download não começou ou parou.

Verifique a conexão com a internet, o espaço livre na pasta de conteúdo e a fila de sincronização. O Sinalo processa uma solicitação por vez para não sobrecarregar o computador.

O vídeo não abre ou abriu no player errado.

O Sinalo tenta usar o MPV que acompanha o aplicativo. Se ele não estiver disponível, tenta o VLC e, por último, o programa padrão do Windows. Reinstale a versão oficial se o MPV estiver ausente e confira a tela de saída configurada.

O vídeo abriu na tela errada.

Abra Configurações, selecione a tela de saída desejada e confirme. Verifique também se o monitor está ligado e reconhecido pelo Windows antes de abrir o vídeo.

O computador ficou sem espaço.

Escolha outra pasta de conteúdo com espaço suficiente. Para arquivos maiores, o Sinalo verifica o espaço antes e durante a sincronização e bloqueia a operação de forma segura quando necessário.

A atualização não foi instalada.

Feche o Sinalo e execute manualmente o instalador da release mais recente. Se o Windows alertar sobre segurança, confirme que o download veio do repositório oficial antes de prosseguir.

Relatar um problema

Se precisar de ajuda, abra uma issue no GitHub e informe a versão exibida no Sinalo, o que você tentou fazer, a mensagem apresentada e, se possível, uma captura de tela.
