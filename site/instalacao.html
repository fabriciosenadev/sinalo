Primeiros passos

Instalar o Sinalo

O Sinalo é instalado no Windows e mantém suas configurações e conteúdos separados dos arquivos do programa.

Instalação inicial

  1. Baixe o instalador oficial

    Use sempre a página de releases do projeto ou o botão abaixo.

    Baixar instalador mais recente

  2. Execute o arquivo baixado

    Confirme a instalação e escolha se deseja criar um atalho na área de trabalho.

  3. Abra o Sinalo

    Na primeira abertura, defina a pasta de conteúdo, os programas de vídeo e a tela de saída.

Quando o Windows mostrar um alerta de segurança

O SmartScreen pode alertar para aplicativos novos ou sem assinatura de código reconhecida. Confirme primeiro que o arquivo veio da página oficial de releases do Sinalo.

Importante: não desative a proteção do Windows. Só prossiga quando tiver certeza da origem do instalador e tiver baixado o arquivo pelo repositório oficial.

Atualizar uma instalação existente

Execute o instalador novo normalmente. Ele reconhece a instalação anterior e substitui os arquivos do aplicativo. Também é possível aceitar uma atualização oferecida pelo próprio Sinalo.

Seus conteúdos são preservados

Os arquivos do aplicativo ficam em Program Files. As configurações e os vídeos ficam em uma pasta de dados do operador. Por isso, atualizar ou reinstalar o aplicativo não deve apagar vídeos já baixados.
